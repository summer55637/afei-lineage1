# 阿肥石器時代 V2.71 — 像素世界探索版

V2.71 延續 V2.70 PixelWorld，新增玩家可操作的野外世界層：

- WASD／方向鍵移動
- 手機觸控十字鍵
- 點擊地圖朝指定方向移動
- 村長／補給小屋／採集點／告示牌互動
- 每 3 步使用現有 Encounter 核心進行遇敵檢查
- 遇敵後切回既有戰鬥核心與原 C 邏輯
- 世界位置獨立保存於 localStorage，不改動原戰鬥存檔 schema
- 新玩家自動採用可立即遊玩的安全預設：5/5/5/5、地屬 10、0 號村、起始寵
- 保留 PWA／GitHub Pages／離線快取

## 設計參考
本版的世界／戰鬥場景分離、鍵盤移動與 RPG UI 結構參考公開的 Phaser RPG 專案慣例；沒有直接複製第三方遊戲素材。
