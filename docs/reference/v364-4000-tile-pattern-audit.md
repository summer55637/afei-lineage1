# 4000→200 地形樣式審計

## 目的

在決定是否把 4000 的三格 blocker 打開之前，先確認那三格是不是單純漏掉的道路。

目前邊界是：

`(90,109) → (91,109) → (92,109) → (93,109) → (94,109)`

其 tile 為：

`321 → 409 → 196 → 307 → 156`

## 新證據

這次不改地圖，只統計 fixed source map 裡相同排列是否重複出現。

結果：

| 排列 | 出現次數 | 座標 |
|---|---:|---|
| `321 → 409 → 196` | 2 | `(61,107)`、`(90,109)` |
| `307 → 156` | 2 | `(61,77)`、`(93,109)` |
| 完整 `321 → 409 → 196 → 307 → 156` | 1 | `(90,109)` |

另外，pinned battlefield source manifest 對 tile `196` 的名稱是：

`砂漠の草と土２の境界１`

這表示 `196` 本身是地形邊界 tile，不應該直接把它理解成「壞掉的道路格」。

## 與另一個相似位置比較

4000 另一處有相同的前三格：

`(61,107): 321 → 409 → 196 → 194 → 194 → 193 → 193 → 343`

而 blocker 是：

`(90,109): 321 → 409 → 196 → 307 → 156 → 156 → 150 → 153`

也就是說，前面的 `321 → 409 → 196` 很可能是可重複使用的地形邊界樣式；真正特殊的是後面的 `307 → 156`。

## 判定

目前可以比較有把握地說：

**不能把三格統一換成 321，並把它當作原作地形的恢復。**

原因不是「開路實驗失敗」——實驗仍然成功；而是 source map 的 tile pattern 顯示這裡存在真實的地形樣式結構。

所以目前保留兩件事：

1. 「打通三格」仍是最小、而且已經驗證可執行的 connectivity repair。
2. 「三格應該改成哪種 tile」仍然沒有 source-backed 答案。
