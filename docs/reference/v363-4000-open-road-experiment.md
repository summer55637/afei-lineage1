# 4000→200 開路實驗

## 實驗目的

不修改 fixed-C movement、不新增 teleport，也不改動原本的 mapwarp.txt。

只在記憶體中把 4000 地圖最近斷點的三格：

- (91,109) tile 409
- (92,109) tile 196
- (93,109) tile 307

暫時換成已知可走的地面 tile 321，再使用現有 sourceMapWalkableAt() 做真實移動 BFS。

## 實驗結果

兩個出生落點 (80,90)、(80,91) 都能在實驗版地圖上走到既有的 4000→200 portal origin，而且路徑實際經過這三個被打開的格子。

實驗成功代表：

> 4000→200 的問題確實可以用「打通這三格地形」來解決。

而且不需要新增傳送邏輯；玩家是正常走到原本就存在的 4000→200 Warp。

## 重要限制

這還不是正式修復。

目前只證明「如果這三格變成可走地面，路就會通」。

tile 321 是為了建立可走性實驗所選的現有 walkable tile，並不代表它就是原作這三格應該使用的美術 tile。

因此下一步先確認原始地圖是否存在另一個版本；若沒有，再決定是否建立明確標記為「RO0000 修復版」的 4000 地圖。
