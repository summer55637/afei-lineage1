# 現代 2D 高品質重製手遊視覺與 UI 目標

更新日期：2026-09-30

## 定位

最終作品不再以「舊版網頁石器時代 UI」作為主要呈現目標。

最終產品定位：**單機 PC＋手機跨平台、可長時間遊玩的現代化 2D 石器時代高品質重製放置版。**

最終目標更新為：

**經典石器資料／規則**
→ **現代化 2D 世界、角色與寵物美術**
→ **手機 RPG 等級的 UI / UX**
→ **石器時代式回合戰鬥**
→ **本專案獨有的放置版核心循環**

《石器時代：覺醒》目前官方商店資訊包含正版石器 IP、回合制策略、上百寵物、職業、野外捕捉與離線掛機；《石器時代：放置冒險》則以放置玩法、寵物收集／養成與自動化長時間循環為核心。這兩種方向都可以作為本專案的現代產品參考。

## 視覺目標

### 1. 世界


以高品質 2D 石器時代世界作為最終畫面，不做真正 3D 世界。

最終世界應呈現為：

- 2D 等角／斜俯視卡通場景
- 柔和、鮮明、細緻的 2D 手繪／卡通材質
- 大比例環境物件
- 明顯的地形高低差
- 樹木、岩石、河流、房屋、村莊、道路等可辨識環境
- 保留經典石器時代的村莊與世界識別元素
- 地圖仍以 fixed C 的 floor / warp / encounter / NPC data 作為行為底層

現代 2D 重製版的重點不是單純放大原始 tile，而是讓固定 source 的世界資料以高品質 2D 美術重新呈現；必要時重製角色、寵物、場景與特效，但不改成真正 3D。

### 2. 角色與寵物

角色與寵物改為：

- 高品質 2D 角色／寵物美術
- 大頭／大眼／誇張輪廓，維持石器時代卡通識別
- 清楚的 silhouette
- 飽和但不刺眼的色彩
- 明確的表情與待機動作
- 移動、攻擊、受傷、死亡、召喚等動畫

原版 source 決定「這是誰、數值是多少、技能怎麼算」；現代 presentation 決定「它長什麼樣、怎麼動」。

### 3. 鏡頭

主要世界鏡頭：

- 斜俯視
- 可有限度旋轉／縮放
- 角色維持畫面視覺中心
- NPC、道路、互動物件保持清楚可讀
- 戰鬥時自動轉換至戰鬥構圖
- 手機橫向與桌面寬螢幕都要有一致資訊層級

## UI 目標

本專案以「依實際授權範圍做最高還原」為目標。

若授權涵蓋特定現代石器手游的 UI、版面、icon、字體或其他畫面資產，最終版本可以直接使用相應授權內容；若只涵蓋石器時代 IP 而未涵蓋特定商業版本資產，則以同等資訊架構與操作體驗重新製作 2D 美術與介面。

### 世界 HUD

主畫面應具備：

- 玩家頭像
- HP / MP
- 等級
- 戰力／核心狀態資訊
- 金錢／主要資源
- 寵物快速資訊
- 任務追蹤
- 自動戰鬥／掛機狀態
- 地圖／區域入口
- 聊天／系統訊息
- 快速功能列

### 左下角區域

作為行動與資訊區：

- 虛擬方向控制／自動移動狀態
- 快捷功能
- 表情／社交入口
- 小地圖或地圖按鈕

### 右下角區域

作為主要操作區：

- 普攻
- 技能
- 防禦
- 召喚／換寵
- 自動戰鬥
- 回合或倒數狀態

### 戰鬥畫面

戰鬥 presentation 必須接在既有 battle result event 上，而不是重新計算規則。

畫面包括：

- 2D 戰場
- 敵我雙方站位
- 玩家／寵物高品質 2D 美術
- 頭頂 HP / 狀態
- 傷害數字
- 技能名稱／技能特效
- 目標指示器
- 回合／倒數提示
- 普攻、技能、防禦、召喚等操作
- AUTO
- 戰鬥速度
- 勝負結果
- 掉落與經驗結算

公開的《石器時代 M》戰鬥畫面可看到回合倒數、頭頂生命條、技能／普攻／防禦／召喚操作，以及 AUTO 類控制；這類「戰鬥內容集中在中央、操作集中在底部」的資訊結構可作為我們的參考方向。

## 村莊與 NPC

出生村不再只是「可走的 tile map」，而要成為真正可辨識的高品質 2D 場景。

每個 hometown 至少要有：

- 村入口
- 長老／關鍵 NPC
- 商店
- 家族／銀行等服務
- 傳送點
- 新手引導 NPC
- 地標
- 道路
- 可辨識建築

NPC UI 採：

- 頭頂名字／稱號
- 任務／可互動提示
- 靠近後提示
- 面向 NPC 開啟對話
- 互動視窗
- 商店／服務獨立面板

固定 C 的 NPC interaction distance / facing 規則仍保留為行為來源。

## 轉場與操作節奏

要接近現代手機 RPG 的使用體驗：

進入地圖
→ 鏡頭定位
→ 角色移動
→ NPC / 地圖互動
→ 遇敵
→ 戰鬥鏡頭轉換
→ 回合操作／AUTO
→ 戰鬥演出
→ 結果面板
→ 回到世界
→ 繼續掛機

避免：

- 大量舊式網頁表格
- 多個獨立 HTML 頁面
- 每個系統跳往不同網站
- 沒有一致視覺框架的測試 UI

## 放置版整合

本專案的差異化核心是「固定 C 規則 + 石器時代授權內容 + 單機網頁 + 放置版循環」。現代石器手游的具體畫面與功能是否直接採用，依授權文件所涵蓋的內容決定。

放置版應在現代 UI 中加入：

- 一鍵開始掛機
- 自動尋路
- 自動遇敵
- 自動戰鬥
- 補血／補魔門檻
- 自動換寵
- 自動逃跑
- 自動回城
- 自動補給
- offline progress
- 掛機收益摘要
- 長時間運作統計

這些屬於本專案的產品層規則，必須與 fixed C parity 分開標記。

## 素材原則

需要建立高品質 2D 美術與動畫資產管線：

source identity / gameplay data
→ 2D character / environment art
→ sprite / animation
→ effects
→ runtime presentation
→ UI presentation

原版 client asset 在確認屬於實際授權範圍後，可以直接搬入並作為正式 runtime asset；沒有授權證據的外部素材仍只作研究參考，不進 production。

因此本專案不再把「逐像素 UI／原始美術資產不得直接使用」列為普遍限制；真正的界線改為「是否在本專案實際授權範圍內」。在授權涵蓋的前提下，UI、素材、模型、貼圖、icon、字體、動畫與畫面可以朝高還原甚至原始呈現方向整合。

## 完成標準

在最後 playable 版本中，玩家應感受到：

「這是一款現代化 2D 卡通石器時代 RPG」，而不是「把舊石器網頁放大」。

同時底層仍然要能追溯：

- 地圖來自哪張 fixed-C source map
- NPC 來自哪個 source create block
- 遇敵來自哪個 encounter group
- 技能／戰鬥結果來自哪個 source contract
- 哪些規則是原版 parity
- 哪些規則是本專案新增的放置版規則

這是本專案最終視覺方向的正式規格。
