# 視覺參考 001：使用者提供影片 1.mp4

來源：本次對話由使用者提供的遊戲影片。
用途：作為本專案後續「高還原 Stone Age 遊戲體驗」的視覺與操作參考，不取代 fixed C 規則。

影片規格：
- 約 5 分 39 秒
- 1920×1080
- 30 FPS

## 影片中需要記住的整體風格

### 世界／主畫面
- 俯視 2D／等角感地圖，整體是明亮、細緻、飽和的石器時代幻想場景。
- 野外有樹木、草地、道路、岩石、溪流、村落建築、裝飾物與 NPC。
- 玩家角色與寵物直接站在地圖上，角色比例偏小，地圖資訊量高。
- 頂部、左側、右側、底部都有常駐 HUD；遊戲畫面不是只有中央場景。
- 右側可以同時存在任務／系統資訊欄與功能按鈕。
- 底部有聊天／系統訊息與主要功能入口。

### 戰鬥畫面
- 戰鬥仍是完整的地圖式戰場，不是獨立的黑底／純 UI 戰鬥框。
- 玩家隊伍與敵方隊伍分列兩側，角色／寵物彼此有清楚的站位。
- Battle HUD 會顯示回合、隊伍角色／寵物 HP／MP 等資訊。
- 選擇目標時，場上會直接出現醒目的目標標記／圈選。
- 戰鬥 UI 保留明顯的「攻擊／防禦／技能／捕捉」等操作入口。
- 敵我位置與目標選取視覺應該成為我們日後戰鬥場景還原的重要基準。
- 傷害、狀態、技能演出需要直接疊在戰場上，而不是只改數值文字。

### 角色／寵物／屬性頁
- 角色與寵物資訊使用大型紙本／卷軸感面板。
- 頭像、角色立繪／模型、元素、生命、氣力、攻擊、防禦、速度等資料集中於同一層級。
- 屬性欄位有大量固定位置與視覺化條列，不是一般 HTML 表格。
- 右上與右側有明確分頁／切換入口。

### 加點／培養
- 「加點攻略」類介面以完整彈窗呈現。
- 有角色傾向、推薦分配、屬性增加與啟用按鈕。
- 自定義加點使用 +/- 控制與即時數字。
- 因此未來玩家養成介面不應只做簡單 input，而要以遊戲面板形式呈現。

### 商店／活動／禮包
- 有大型活動 Banner 與獨立商品／套餐頁。
- 商品列表以多段大型卡片排列，價格與購買按鈕固定在右側。
- 這類面板與戰鬥、角色資訊使用不同的視覺層級，但仍維持同一套石器 UI 語言。

### 寵物技能
- 寵物頁面以左側寵物清單＋中央技能清單＋右側已裝技能槽的三欄形式呈現。
- 技能有圖示、名稱、說明、學習／升級價格。
- 已裝技能槽用固定位置的「+」框表示。
- 這種三欄資訊結構可作為後續技能／寵物頁的視覺參考。

### 戰鬥設定
- 有獨立「戰鬥設定」頁。
- 可分別設定人物與寵物的首次／一般行動。
- 行動選擇使用下拉／選單式控制，不是純文字指令。
- 另有補血相關設定與百分比門檻。

### 掛機／離線
- 戰鬥中可以開啟「離線掛機」視窗。
- 視窗明確顯示剩餘次數／時間，以及取消／確認按鈕。
- 這代表「掛機」不是單純一個背景計時器，玩家端應該有清楚的視覺流程。

## 對本專案的實際意義

這支影片提供的不只是「配色參考」，而是後續 UI／戰鬥／場景重製時的 layout reference：

1. 世界場景要有真正的石器時代地圖感。
2. 戰鬥要在場景上呈現，而不是做成單純數值面板。
3. 玩家、寵物、敵人要有固定且可辨識的戰場站位。
4. HUD、任務、聊天、功能入口要形成完整遊戲介面。
5. 角色／寵物／技能／設定／掛機都要有獨立的遊戲式面板。
6. 未來做 V2.70+ 視覺層時，以「版面、層級、操作流程、演出節奏」為還原目標。
