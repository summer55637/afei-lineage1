# V4.13 Browser Battle EXP Plan

## Source boundary

Pinned source: `gavinlinasd/StoneAge@1f90cb6cb57c1df70f39cde77a5a8ccd98b66c56`.

Fixed C uses `BATTLE_GetExp()` before `BATTLE_GetExpGold()` records the result. With the current pinned build, `_NEWOPEN_MAXEXP`, `_GET_BATTLE_EXP` and `battleexp=100` are active. The exact source sequence is: read `CHAR_WORKGETEXP`; clamp the staged input to `0..1,000,000,000`; apply optional item EXP modifiers when that feature exists; multiply directly by `getBattleexp()` (current value 100); zero the result at `CHAR_MAXUPLEVEL` or higher; then `CHAR_AddMaxExp()` stores the character EXP with an absolute cap of `1,224,160,000`.

## Browser contract

V4.13 is read-only. It plans the EXP write for the player and each live persistent pet with positive `workGetExp`, but it does not mutate Persistent State.

The player entry must match the persistent player identity. When both BattleContext and Persistent State expose `workGetExp`, they must agree. The active pet receives the same consistency check; other pets use their own persistent staged `workGetExp`, matching the fixed `BATTLE_GetExpGold()` loop over held pets.

The current source `setup.cf` contains `battleexp=100`, and the fixed C multiplies by this raw value. Therefore the current source-closure plan uses ×100, not ×1.0.

## Deferred boundaries

`CHAR_LevelUpCheck()` is deliberately not folded into V4.13. In fixed C it is a separate operation after `BATTLE_GetExp()`, and under the current `_USER_EXP_CF`/`_TRANS_LEVEL_CF` path it depends on the loaded EXP table plus transformation/level-cap gates.

Battle item transfer remains separate as well. `BATTLE_GetExpGold()` can move up to the existing `getitem` pool into the player inventory and sends an `RS` payload; that will be implemented after the EXP and level-up boundaries are closed.

No Gold is generated by this path. Existing project documentation and the fixed `BATTLE_GetExpGold()` body show general PvE battle settlement handling EXP and carried battle items, not a fabricated per-enemy Gold reward.
